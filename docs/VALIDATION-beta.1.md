# Hide v1.0.0-beta.1 验证报告

日期：2026-10-02。对象：本机 Windows x64、已安装的特定 Ikaros 指针文件。当前版本按文件 SHA256 限定兼容范围。

## 发布构建

MSVC 14.51.36231、Windows SDK 10.0.26100.0、C++17 Release /O2 /MT /W4 /guard:cf。编译通过，无警告。状态测试通过 20,044 条断言，包含 10,000 次状态转换，以及字符键、快捷键／修饰键、焦点竞态、编辑延续、鼠标优先恢复和暂停。

发布前检查了环境变量展开结果的长度边界，并使重复启动保持现有实例的状态。

## 皮肤与真实输入

核对 17 个系统原文件与转换前 SHA256，全部一致。验证 68 个转换文件：ANI 帧数、帧序、速度、尺寸和热点保留，CUR 尺寸和热点保留；隐藏版无 XOR 反色像素。

原构建的桌面输入测试实际绘制系统指针测量 alpha，结果如下（evidence/baseline-opacity-tests.json）：

| 设置 | 淡化后 alpha / 255 | 恢复后 alpha / 255 | 首字符至完成淡化 |
| --- | --- | --- | --- |
| 50% 透明 | 128 | 255 | 62 ms |
| 75% 透明 | 64 | 255 | 47 ms |
| 90% 透明 | 26 | 255 | 62 ms |
| 完全隐藏 | 0 | 255 | 78 ms |

原构建连续 30 次淡化／恢复成功，热身第 5 次到第 30 次，内核句柄 548→546，GDI 58→57，USER 96→95；短时结果未见持续句柄增长，不能据此排除长期泄漏。

Hide 命名构建另通过首字符测试：47 ms、淡化 alpha 64、恢复 alpha 255，见 evidence/hide-integration.json。输入测试要求自己的窗口和 EDIT 同时取得前台／输入焦点；不满足时中止字符注入。

## 异常恢复

Hide 的独立恢复测试直接激活实际系统指针淡化，核对 alpha 后强制终止自己的主进程（99）。守护进程清除未完成恢复标记，原 Arrow／IBeam 路径及 Ikaros 方案保留，见 evidence/hide-guardian.json。此测试独立于前台输入检测，不发送按键。

退出、暂停、鼠标操作、空闲、窗口切换、会话与电源事件都有恢复路径；锁屏／休眠真实循环和连续多重故障尚未完整实测。

## Hide 常驻资源

30 秒样本包括主程序和恢复守护，不包括临时状态查询进程。此样本无键鼠操作。

| 指标 | 开始 | 结束 |
| --- | --- | --- |
| 主程序私有内存 | 4.77 MiB | 4.92 MiB |
| 守护私有内存 | 1.51 MiB | 1.42 MiB |
| 私有内存合计 | 6.28 MiB | 6.34 MiB |
| 工作集合计 | 37.07 MiB | 37.18 MiB |

累计 CPU 时间增加 0.046875 秒，采样 30.010 秒，约占单核 0.16%。Windows 时间计数存在粒度；此值不代表所有负载和长期使用。私有内存不含共享 DLL，工作集包含当前驻留及共享页面，两者不能互相替代。打开测试窗口／输入法时会出现更高占用。

原始样本见 evidence/hide-resident-benchmark.json。
