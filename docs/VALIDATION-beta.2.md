# Hide v1.0.0-beta.2 验证报告

日期：2026-10-03（Asia/Shanghai）。对象：本机 Windows x64 交互桌面与已安装的指针样本。发布仍为 Beta。

## 结果与绑定修复

运行中自动读取每个系统指针角色、类型和文件变化，生成对应透明副本。淡化只替换内存中的系统指针，正常路径不写用户的角色配置；恢复、退出和守护以当前 Windows 配置为准。启动时的某套皮肤不再作为永久绑定来源。

原问题现场中，方案标签为 Default、实际角色为 Ikaros。确认首版固定资源和缺少重新绑定；没有完整复现首次导致记录不一致的覆盖瞬间。新版验证了切换后的输入、恢复与故障不会把角色记录写回旧皮肤，直接消除了这类临时路径写入。

## 原生格式与实际绘制

- MSVC C++17 Release /O2 /MT /W4 /guard:cf，编译无警告。
- 原有输入状态：20,044 条断言，含 10,000 次转换、Backspace 编辑延续、鼠标优先和焦点竞态。
- 新增原生光标测试：18,582 个检查，含 10,000 次有界变异、截断／范围／重叠检查、PNG、多个图像、动画帧序／速率／热点与黑白反色。
- 黑、白和灰色背景实际绘制验证普通颜色、部分 alpha 与反色的 50%、75%、90% 和隐藏混合效果。正确处理文件 RGB 与 Windows 加载后的预乘颜色，隐藏版不会留下反色像素。
- 17 个系统角色另通过测试动画指定帧与序列比较。实测 CopyIcon 会将 ANI 扁平化，因此动画使用完整文件加载后交给 SetSystemCursor。
- 空来源的默认角色读取系统资源；检测到动画且无法恢复完整来源时拒绝半透明，保留当前外观，避免将动画截图作为整体来源。

本机文件扫描：**223／223** 转换、元数据复核及 Windows 加载通过，其中 **185 CUR、38 ANI**，包括 **57 个含黑白反色像素的文件**。PNG 使用合成样本验证，目录样本不能代表所有来源。源文件未被改写。

## 桌面方案生命周期

[evidence/dynamic-scheme-desktop.json](../evidence/dynamic-scheme-desktop.json)记录：

1. Ikaros、保存的 Default 与系统默认空路径方案，输入后端淡化／恢复保留当前角色记录。
2. 淡化中换方案，之后淡化和恢复处理新方案。
3. 102 次快速切换，最终方案生效。
4. 混合方案只改 IBeam，其他角色保持。
5. 相同路径的文件替换重新识别；损坏文件不加载，保留当前配置。
6. 1,000 次真实系统淡化／恢复，内核句柄 366→359，GDI 7→7，USER 44→43，未见持续增长。
7. 淡化后选择新方案并强制终止主程序，守护完成恢复且保留新选择；再次启动、退出也保留新选择。

1,000 次循环抽取 40 个执行淡化时间样本，P95 **61.825 ms**，最大观测 **92.604 ms**。它是后端执行时间，区别于从按键到显示的完整延迟。最终候选另通过同一矩阵的 50 次复核，见 [final 数据](../evidence/dynamic-scheme-final.json)。

桌面方案脚本不注入文字，finally 恢复测试前设置；测试源替换只在 build/ 的私有副本中进行。

## 首字符与恢复

[evidence/dynamic-input.json](../evidence/dynamic-input.json)的受控 EDIT 测试，仅在测试输入框拥有焦点时注入字符：

| 透明设置 | 首字符到淡化 | 淡化 alpha 最大值 | 恢复 alpha 最大值 |
| --- | --- | --- | --- |
| 50% | 47 ms | 128 | 255 |
| 75% | 47 ms | 64 | 255 |
| 90% | 47 ms | 26 | 255 |
| 隐藏 | 47 ms | 0 | 255 |

这些是当前样本，不是全部软件的延迟保证。反色透明的等效混合使用专门背景测试解释，不能简单对比 alpha_max。

## 常驻开销与长期观测

短时报告见 [dynamic-resident.json](../evidence/dynamic-resident.json)。测量包含主程序和守护，排除查询及观察助手；私有内存与工作集分别统计。30 秒轻负载样本无文字输入、包含 46 个鼠标事件：主程序与守护合计私有内存 **6.16→6.19 MiB**，工作集 **31.16→35.52 MiB**。累计 CPU 时间增加 0.03125 秒，约占单核 **0.10%**；受计时粒度与短样本限制。

8 小时持续观测尚未完成，不能把 1,000 次循环或 30 秒样本当作长期测试。开发者可运行 tests/observe_resident.ps1，按实际负载、起止、是否中断及内存／句柄趋势复核。本机长时结果写 state/soak-validation.json，个人运行数据不随公开便携包上传。

## 兼容性与限制

- 常见 CUR／ANI、多尺寸、PNG、1／4／8／16／24／32 位常见 DIB、黑白反色受到原生处理。
- 复杂彩色 XOR、特殊压缩、嵌入颜色配置、超过 256 像素的显示尺寸或资源上限可能受限。文件／转换输出各有 32 MiB 上限，当前方案输出缓存总量上限 64 MiB；大皮肤的实际占用会高于典型样本。
- 未完整覆盖所有 Windows 版本、全套中文输入法、所有浏览器／编辑器、管理员窗口、自绘鼠标、游戏和真实锁屏／休眠循环。
- 当原文件不可读、格式不支持或任务失效时，保留当前外观；支持结果以实际通过的格式和方案为准。

## 便携包与源码

发布包不携带固定皮肤素材，运行使用用户已安装的当前皮肤，转换不需要 Python 或 Codex。便携包已在干净目录启动，确认默认 75%、自动识别完成、重复启动保留实例及正常退出。可执行文件 327,680 字节；实际包大小与哈希以发布资产及 SHA256SUMS.txt 为准。见 [portable 数据](../evidence/dynamic-portable.json)。公开下载校验在发布后执行。
