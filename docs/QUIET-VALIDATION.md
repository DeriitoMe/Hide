## 实际发现与处理

两种启动上下文读取的本机用户配置不同：直接启动读取 Ikaros，Windows 任务读取 Default，但全部 17 个可见角色都匹配用户指定的 Ikaros。备份并核对全部角色后，一次性对齐本机实际配置，没有重载或替换可见指针。该操作不属于程序运行逻辑，相关个人备份及脚本不打包。

Windows 任务的 RestartOnFailure 设置没有在强制结束引擎后实际恢复。因此改为由现有恢复守护兼任监督进程，原生完成最多 3 次异常引擎重启；监督也退出时由周期健康检查补上。正常退出暂停健康检查；下一次登录或明确启动恢复。恢复失败或短时重试预算耗尽时停止检查并保留证据。

首次显示设置时，隐藏启动器的 STARTUPINFO 会影响 ShowWindow。已修复首次可见性，并额外核对 IsWindowVisible，避免只检查窗口存在。

任务最后结果与当前运行状态分开记录。重复启动被拒绝时，最后结果可能非零；判断当前健康仍应核对活跃 PID、hooks_ready、guardian_alive、supported 与 preparing。
