# Hide v1.1.0 执行要求

日期：2026-10-07（Asia/Shanghai）。

将已有静默运行、监督恢复和登录启动成果完善并发布为 v1.1.0。先核查已完成的功能，避免无必要重写。

1. 新用户首次启动显示原 Hide 托盘图标和清晰引导。关闭设置窗口后继续运行；用户主动取消显示托盘进入静默模式。已有用户的透明度、恢复方式、启用状态和托盘选择保持原样。
2. 新安装首次设置默认启用当前用户登录启动，界面显示真实登记结果。用户关闭自启或禁用任务后不擅自重新开启。已有启用的传统启动项可迁移到当前用户任务。
3. 静默模式保留输入淡化、换肤跟随及自启。提供桌面设置快捷方式和 Ctrl+Alt+H 入口，使用原图标；打开设置复用已有实例，不创建重复输入引擎。
4. 登录启动、引擎异常恢复和监督丢失恢复分别验证。正常退出暂停本次会话的健康检查，保留下次登录启动；关闭设置窗口不能被当成退出。
5. 换肤后使用最新角色及动画来源，恢复也使用最新方案。不得绑定原皮肤或自动选择其他命名方案，测试前后恢复用户原来的配置及外观。
6. 核查实际内存、CPU、句柄和驻留报告。区分私有内存、工作集、短时样本与长期验证；未完成或中断的观测不能写成通过。
7. 完成构建、功能与故障回归、干净包启动、图标和引导检查后，上传源码并发布正式 v1.1.0 Release，保留 v1.0.0 历史版本。同步中英文教程、更新记录、验证范围、便携 ZIP 和 SHA256，复核公开下载。
