# 发布规范

1. 按实际通过的格式与桌面测试说明支持范围；发布名称、标签和类型采用已确定的版本规范，不夸大验证覆盖。
2. 更新版本、README、中英文下载教程、CHANGELOG 和验证报告。
3. 执行 build.ps1；CI 执行相同输入状态与原生光标测试。交互桌面测试另运行，不以无交互 CI 代替。
4. 生成便携包，检查 ZIP 结构、可执行文件一致性、干净目录启动及 SHA256。排除个人 state/、缓存、恢复日志、凭据和第三方测试皮肤。
5. 发布 Hide-windows-x64.zip 与 SHA256SUMS.txt，说明兼容范围和验证限制。
6. README 与教程使用公开浏览器下载链接。预发布用固定标签地址，稳定版可用 releases/latest/download/Hide-windows-x64.zip。
7. 从公开下载地址重新下载，核对 SHA256、源码提交、标签与资产，检查 Windows CI。

常驻观测尚在进行时，不能写为长期测试已通过。补充结论需附起止及实际样本。项目不自动发布 Release。
