# Hide v1.0.0 验证报告

日期：2026-10-05（Asia/Shanghai）。范围：本机 Windows x64、已安装皮肤及合成格式样本。

## Backspace 与系统打字隐藏

本机 Windows 的“在打字时隐藏指针”实际处于开启状态，能够让已淡化的指针完全消失。现在 Backspace／Ctrl+Backspace 可独立触发当前透明度；Hide 启用且皮肤准备完成时临时关闭系统打字隐藏，暂停、退出及守护恢复时还原。调用不使用永久偏好写入标志，恢复标记记录进程归属，避免旧守护消费新实例的标记。

[backspace-validation.json](../evidence/backspace-validation.json)记录本机受控测试与生命周期检查：

- --backspace-test 75：从固定测试文字独立删除，再连续删除 8 次；指针实际可见，最大 alpha 为 64（约 25% 不透明），鼠标移动后恢复为 255。首个模拟 Backspace 到淡化为 47 ms，仅代表本次受控样本。
- 临时关闭、暂停还原、重新启用和正常退出通过；原本关闭系统打字隐藏时保持关闭，不创建恢复标记。
- 未淡化时强制终止，以及淡化时 --crash-test 终止，守护均恢复系统打字隐藏；后者同时恢复指针。
- 遗留恢复标记的 --recover 与下次启动恢复通过，新实例取得自身进程标记。
- 测试前后的持久鼠标偏好、全部指针角色路径和方案名称相同。

半透明集成测试现在检查 GetCursorInfo 的 CURSOR_SHOWING，除指针对象的透明度外，还核对指针实际处于显示状态。这次没有重新运行完整换肤矩阵或数小时常驻测试。

## 本次皮肤保护修复

现场发现方案名称为 Default，但 17 个角色路径均指向 Ikaros，名称与保存方案不一致。已按用户明确要求把本机名称和角色统一为 Ikaros。这是一次本机配置纠正；发布程序不包含指定皮肤、角色路径或自动选方案的逻辑。

未完整重现最初从 Ikaros 跳到另一皮肤的触发瞬间。额外发现 Windows 重载接口返回成功后，Person 的实际图像仍与配置文件不同。逐角色恢复修复后，17 个角色的实际图像均与配置来源一致。旧验证只核对角色记录，缺少这种显示身份校验。

现在准备与淡化前均校验实际图像、热点和前三个动画采样帧，覆盖黑白背景。配置与显示不一致时拒绝淡化并保留可见皮肤，提示重新应用用户希望使用的方案。恢复先重载 Windows 默认角色，再逐一加载最新自定义来源，保留完整 ANI；正常路径不写皮肤偏好、不选保存的命名方案。

动画身份检查使用采样帧，不能证明任意第三方绘制器或任意动画均相容；支持范围仍以实际测试为准。

## 回归证据

[skin-safety.json](../evidence/skin-safety.json)与 [测试脚本](../tests/skin_safety_validation.py)：

- 连续 100 次淡化／恢复，每次均核对 17 个角色的实际显示图像、热点、采样帧与原始配置相同。
- 不通知 Hide 而改变箭头的内存图像，下一次淡化被拒绝，未替换可见图像、未写配置；重新应用后可恢复使用。
- 淡化中强制终止、守护恢复、重启及淡化中退出，均保留原有显示外观与角色配置。
- 后端淡化时间 P95 70.047 ms，最大观测 73.725 ms；它不等于按键到显示的完整延迟。
- GDI 句柄 19→19，USER 48→49；内核句柄 369→374 后连续采样保持 374，未见后半程持续增长。异步 UI Automation 初始化与持续增长分别检查。
- 主程序与守护合计私有内存约 6.36→6.47 MiB，工作集约 37.17→37.27 MiB。这是循环回归中的样本，不是新版长期驻留结论。

最终版本资源更新后，本机正式实例启动检查：enabled、supported 和 startup 均为 true，透明度为 75%。注册启动项指向当前可执行文件；没有模拟实际重启登录。

## 原生与历史覆盖

MSVC C++17 /O2 /MT /W4 /guard:cf，构建无警告。输入状态 20,104 条断言、原生格式与绘制 18,594 个检查通过，包含 10,000 次格式变异、显示身份检查与删除输入回归。

开发阶段已验证本机 223 个 CUR／ANI 的转换及加载、1,000 次桌面恢复、102 次快速换肤、混合方案、同路径文件更新、四种透明设置的受控首字符响应及便携包运行。本次保留对应代码，但没有重新跑完整历史矩阵；见 [开发阶段报告](https://github.com/DeriitoMe/Hide/blob/main/docs/VALIDATION-beta.2.md)及原始证据。

开发阶段 8 小时观测已完成：481 个样本，合计私有内存 6,299,648→6,389,760 字节、工作集 37,294,080→37,937,152 字节、句柄 466→468；期间无键盘或鼠标事件增长，属于空闲观测。它不是本次皮肤保护修复后的 8 小时测试。本机完整数据在 state/soak-validation.json，个人运行数据不随发布包分发。

## 开机启动与发布

右键托盘 → 随 Windows 启动，或 --enable-startup／--disable-startup。命令幂等，记录当前真实 exe 路径，失败时提示；--status 的 startup 字段核对路径是否相同。默认不为下载者开启，用户自行勾选。

最终 Hide.exe 为 340,480 字节，SHA256：

9ec551957c4a686d6af60d3e884ebcb60aad30fff7428032112351a865eebb65

便携包明确排除 state/、个人恢复记录、皮肤素材、证据、测试与开发工具。ZIP 与 SHA256 由 tools/package_release.py 生成并核对。

## 限制

常见 CUR／ANI、多尺寸、PNG、常见 DIB 与黑白反色受到支持；特殊彩色 XOR、压缩位图、超限资源及完整来源不可取得的系统动画可能受限。文件／转换输出各限 32 MiB、显示尺寸限 256 像素、方案输出缓存限 64 MiB。

尚未完整覆盖所有皮肤、Windows 版本、输入法、管理员窗口、自绘光标、游戏及真实锁屏／休眠循环。检测到不一致或不支持时保留外观并暂停淡化；不承诺零缺陷。
